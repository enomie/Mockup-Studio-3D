# Pläne

Hier liegen Pläne (`plan-<thema>.md`) **während** an einem Thema gearbeitet wird (Regel in `AGENTS.md`: erst Plan, dann Code nach Freigabe).

Ist ein Plan umgesetzt, wird er **gelöscht**:
- das „Wie es jetzt ist“ wandert in eine Feature-Doku (z. B. `_docs/triangle-patch/`) oder die Requirements,
- das „Warum“ und verworfene Wege ins Tagebuch `_docs/diaries/diary-code-decisions.md`,
- der Plan selbst bleibt in der Git-Historie.
